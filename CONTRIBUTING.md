# Участие в проекте

Предлагайте изменения через pull request. Не прикладывайте реальные ссылки `tg://proxy`, содержимое конфигураций действующих VPN, токены, приватные SSH-ключи, пароли restic и OAuth-файлы.

Перед PR проверьте установщик командой `bash -n scripts/install-mtproto.sh` и перечитайте PDF после любых изменений руководства.
